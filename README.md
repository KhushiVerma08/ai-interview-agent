# AI Interview Agent

AI-Powered Adaptive First-Round Interview Agent.

## Overview

This project is an AI-powered agent designed to conduct first-round interviews. It runs a web application that facilitates the interview process.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the server:
   ```bash
   npm start
   ```

The agent will be running at `http://localhost:3000`.

## Features
- Interactive AI Interviewer
- Upload candidate documents (resumes, etc.)
- Automatically generate interview reports

## Environment Variables
Create a `.env` file based on `env.example` and fill in the required configurations.
